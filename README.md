# Coding-lab_Group25
KNH Digital Infrastructure Project

Project Overview
This project was developed by five programmers for Kenyatta Hospital (KNH) Digital Infrastructure. Created to securely manage and analyze data generated by hospital sensors using Shell Scripting. The system includes environment setups, data security, log analysis, and log archiving, following proper Git collaboration practices.

Instructions
1. Start simulator:
	python3 hospital_system.py starts
2. Stop the simulator:
	python3 hospital_system.py stops
3 Run the administration script:
	./hospital_admin.sh
4. Run the analysis script:
	./hospital_analysis.sh
5. Run the archive script:
	./hospital_archive.sh
